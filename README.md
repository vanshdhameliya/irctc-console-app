# 🚆 IRCTC Console App

A console-based IRCTC Ticket Booking Application developed using Core Java.

This project simulates the basic functionality of the IRCTC railway reservation system where users can register, log in, search trains, book tickets, view booked tickets, and cancel tickets.

---

## ✨ Features

- 👤 User Registration
- 🔐 User Login & Logout
- 🚆 Search Trains
- 🎫 Book Ticket
- 📄 View Booked Tickets
- ❌ Cancel Ticket
- 🚉 Train Management
- 📚 Object-Oriented Programming
- 📂 Collections Framework (ArrayList & HashMap)

---

## 🛠 Technologies Used

- Java
- OOP
- Collections Framework
